# Özel ses efektleri (isteğe bağlı)

Varsayılan sesler tarayıcıda sentezlenir. Kendi seslerinizi kullanmak için dosyayı
aşağıdaki adlardan biriyle buraya koyun (`.mp3`, `.wav`, `.ogg`, `.m4a`):

`explode`, `bomb`, `mine`, `meteor`, `pop`, `boost`, `nitro`, `jump`, `rocket`,
`teleport`, `fuel`, `repair`, `shield`, `block`, `change`, `win`, `bad`, `gift`,
`wind`, `land`

Örnek: `explode.mp3` her patlamada çalar.
