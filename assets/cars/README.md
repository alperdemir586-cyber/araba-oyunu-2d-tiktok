# Araç görselleri

Masaüstündeki **dosyalar 2d** klasöründeki araba PNG'lerini buraya kopyalayın
(veya sunucuyu `CARS_DIR="C:\Users\...\Desktop\dosyalar 2d"` ile başlatın).

- Araç yan görünüşte, **sağa bakacak** şekilde olmalı; arka planı şeffaf PNG en iyisidir.
- Panel → **Görseller** → *Özel araçlar* bölümünden her görseli araç olarak açın,
  tekerlek ve koltuk konumlarını önizlemeden ayarlayın.
- Camı/üstü açık araçlarda "Üstü/camı açık" seçeneğini işaretleyin; sürücü,
  görselin şeffaf cam boşluğundan görünür.
- Tekerlek ayrı bir görselse (ör. `teker.png`), aracın "Teker görseli" alanından seçin.
