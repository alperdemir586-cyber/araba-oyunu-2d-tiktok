# Zemin görselleri

Zemin dokularını buraya koyun ve Panel → **Görseller**'den haritaya atayın.

- **Şerit** modu: görselin üst kenarı (çim/kar/asfalt) yokuşun yüzeyini takip eder,
  altı görselin en alt satırının rengiyle doldurulur. Hill Climb tarzı zemin şeritleri için.
- **Desen** modu: görsel tekrar eden doku olarak zeminin tamamına döşenir.
- *Genişlik (m)*: görselin genişliğinin oyunda kaç metreye karşılık geleceği.
