# Hediye görselleri

Masaüstündeki **tiktok-hediye** klasöründeki görselleri buraya kopyalayın
(veya sunucuyu `GIFTS_DIR=...` ile başlatın).

Dosya adı hediyenin adı olarak kullanılır (`Rose.png` → "Rose"). TikTok olaylarında
hediye adları İngilizce gelir; kuralların eşleşmesi için dosya adlarını TikTok'taki
adlarla aynı yapın (büyük/küçük harf, boşluk ve `_`/`-` önemsizdir). Panel → Kurallar →
*Hediye listesi*'nden bir hediyeye tıklayarak doğrudan kural oluşturabilirsiniz.
TikTok'a bağlıyken yayın odasındaki gerçek hediye listesi de burada görünür.
